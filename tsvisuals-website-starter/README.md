# TSVisuals Website

TSVisualsin julkinen verkkosivusto: palvelut, portfolio ja yhteydenotto.

## Kansiorakenne

```text
index.html        Etusivu
style.css         Sivuston ulkoasu
images/           Portfolio- ja brändikuvat
```

## Käyttöönotto GitHubiin

1. Luo GitHubiin repositorio nimellä `tsvisuals-website`.
2. Kopioi tämän kansion sisältö repositorion juureen.
3. Lisää kuvat `images`-kansioon ja julkaise GitHub Pagesilla.
